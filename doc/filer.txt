INTRODUCTION						*filer-introduction*

filer is a small file explorer implemented in Vim9 script.

It disables netrw by setting |g:loaded_netrwPlugin| and opens a filer buffer
automatically when Vim enters a directory buffer.  A filer buffer uses the
|filer| filetype and shows a tree rooted at the current filer directory.

==============================================================================
COMMANDS						*filer-commands*

							*:Filer*
:Filer [dir]
		Open a filer buffer for [dir].

		When [dir] is omitted, the current working directory is used.  The
		argument is completed as a directory.

>
	:Filer
	:Filer path/to/dir
<

							*:FilerBufferDir*
:FilerBufferDir
		Open the directory of the current buffer in a vertical split and
		jump to the current file.

		When the current buffer is already a filer buffer, reopen the same
		filer directory without resetting expanded directories.

==============================================================================
MAPPINGS						*filer-mappings*

The following mappings are buffer-local to filer buffers.

							*filer-q*
q		Close the filer window.

							*filer-enter*
<CR>		Open the item under the cursor.  Files are edited.  Directories
		are opened as the new filer root.

							*filer-tab*
<Tab>		Duplicate the current filer buffer in a vertical split.

							*filer-t*
t		Toggle expansion for the directory under the cursor.

							*filer-T*
T		Recursively toggle expansion for the directory under the cursor.

							*filer-home*
~		Redraw with the home directory as the root.

							*filer-root*
\		Redraw with the filesystem root as the root.

							*filer-h*
h		Redraw with the parent directory as the root.

							*filer-l*
l		Open the item under the cursor.  Files are edited.  Directories
		are opened as the new filer root.

							*filer-dot*
.		Re-open the current filer directory and redraw the view.

							*filer-space*
<Space>		Toggle the mark on the item under the cursor.

							*filer-star*
*		Toggle marking of all items in the current view.

							*filer-a*
a		Create a file or directory.  A trailing "/" or "\" creates a
		directory.

							*filer-c*
c		When no items are marked, mark the item under the cursor.  When
		items are marked, open a batch copy buffer for the marked items.

							*filer-d*
d		When no items are marked, mark the item under the cursor.  When
		items are marked, confirm and delete all marked items.

							*filer-gg*
gg		Jump to the first entry.

							*filer-r*
r		When no items are marked, mark the item under the cursor.  When
		items are marked, open a batch rename buffer for the marked items.

							*filer-x*
x		Open the item under the cursor with the OS default application.
		On the header line, open the current filer directory.

							*filer-yy*
yy		Copy the full path of the current line to the clipboard register.
		On the header line, copy the current filer directory.

							*filer-CTRL-F*
CTRL-F		Recursively search for file names under the current filer
		directory.  Submit an empty query to clear the search.

		While a search is active, CTRL-F keeps its normal page-down
		behavior.

							*filer-S*
S		Cycle the sort mode: "name" -> "size" -> "time".

CONFIGURATION						*filer-configuration*

							*g:filer_no_default_mappings*
g:filer_no_default_mappings
		When non-zero, filer does not define its default key mappings.
		Buffer-local <Plug> mappings are still defined.

>
	g:filer_no_default_mappings = true

	autocmd FileType filer nmap <buffer> o <Plug>(filer-enter)
	autocmd FileType filer nmap <buffer> q <Plug>(filer-close)
	autocmd FileType filer_rename nmap <buffer> q <Plug>(filer-batch-close)
	autocmd FileType filer_copy nmap <buffer> q <Plug>(filer-batch-close)
<

		Custom buffer-local mappings can also be defined directly with
		<Plug> mappings.

>
	autocmd FileType filer nmap <buffer> <C-B> <Plug>(filer-search)
<

							*g:filer_mappings*
g:filer_mappings
		Dictionary for changing individual default mappings in filer
		buffers.  Keys are action names.  Values are mapping left-hand
		sides.  Use an empty string to disable one action, or a List to
		assign multiple keys.

>
	g:filer_mappings = {
	      'enter': 'o',
	      'parent': 'H',
	      'child': 'L',
	      'search': '/',
	      }

	g:filer_mappings = {
	      'open_external': '',
	      'enter': ['<CR>', 'o'],
	      }
<

		When |g:filer_no_default_mappings| is enabled, only explicitly
		configured actions in g:filer_mappings are mapped.

		Available action names:

		close			<Plug>(filer-close)
		enter			<Plug>(filer-enter)
		duplicate		<Plug>(filer-duplicate)
		toggle_tree		<Plug>(filer-toggle-tree)
		toggle_tree_recursive	<Plug>(filer-toggle-tree-recursive)
		home			<Plug>(filer-go-home)
		root			<Plug>(filer-go-root)
		parent			<Plug>(filer-go-parent)
		child			<Plug>(filer-go-child)
		refresh			<Plug>(filer-refresh)
		toggle_mark		<Plug>(filer-toggle-mark)
		mark_all		<Plug>(filer-mark-all)
		create			<Plug>(filer-create)
		copy_or_mark		<Plug>(filer-copy-or-mark)
		delete_or_mark		<Plug>(filer-delete-or-mark)
		first_entry		<Plug>(filer-jump-first-entry)
		rename_or_mark		<Plug>(filer-rename-or-mark)
		open_external		<Plug>(filer-open-external)
		yank_path		<Plug>(filer-yank-path)
		search			<Plug>(filer-search)
		cycle_sort		<Plug>(filer-cycle-sort)

							*g:filer_batch_mappings*
g:filer_batch_mappings
		Dictionary for changing default mappings in batch rename and
		copy buffers.

>
	g:filer_batch_mappings = {
	      'close': 'q',
	      }
<

VIEW							*filer-view*

The first line shows the current filer directory with a trailing slash.  Entries
start on the second line when present.

Directory entries are shown before files for every sort mode.  Each entry shows
the name, file size, and modification time.  Directories do not show a size.
When a size or timestamp is unavailable, "-" is shown instead.

When the window is too narrow to fit the metadata area, each entry falls back to
showing only the name.

Symbolic links are shown as directories when their targets are directories.
Broken symbolic links are reported when filer tries to open them.

The statusline shows the current directory on the left, and the current sort
mode plus "[current/total]" entry position on the right.

==============================================================================
MARKS							*filer-marks*

Selected items are marked with "*".  Marks are local to a filer buffer.

Marks are cleared when changing directories, when the filer buffer is hidden,
and when the filer buffer is closed.

The delete, rename, and copy mappings use marks as their selection.  If no item
is marked, these mappings first mark the item under the cursor.

==============================================================================
BATCH BUFFERS						*filer-batch-buffers*

							*filer-batch-rename*
Batch rename opens a temporary buffer listing the marked paths.  Edit each line
to the destination path and write the buffer with |:write| to apply the rename.

The number of lines must match the number of source paths, and destination lines
cannot be empty.  Relative destinations are resolved from the filer directory.

							*filer-batch-copy*
Batch copy opens a temporary buffer listing the marked paths.  Edit each line to
the destination path and write the buffer with |:write| to copy the changed
entries.  Unchanged source and destination pairs are skipped.

The number of lines must match the number of source paths, and destination lines
cannot be empty.  Relative destinations are resolved from the filer directory.

Use "q" in a batch buffer to wipe it out without applying changes.

==============================================================================
SEARCH							*filer-search*

Search mode is enabled with |filer-CTRL-F|.  It recursively scans file names
under the current filer directory and displays matching entries as paths
relative to that directory.

Directory expansion mappings do nothing while a search is active.  Submit an
empty search query to return to the tree view.

==============================================================================
SORTING							*filer-sorting*

The default sort mode is "name".  Use |filer-S| to cycle through:

	name	Sort by name.
	size	Sort files by size, largest first.
	time	Sort by modification time, newest first.

Directories are listed before files in every sort mode.  Name order is used as
the final tie breaker.

==============================================================================
SYNTAX							*filer-syntax*

When |:syntax-on| is enabled, filer loads the "filer" syntax file.

The syntax file highlights the header, marks, tree icons, directories, files,
sizes, and timestamps.  Timestamps are color-coded by recency from newer to
older entries.

==============================================================================
LIMITATIONS						*filer-limitations*

Basic operation on Windows is supported within the same drive.  Renaming across
drives on Windows is not supported.

Opening files with the OS default application uses:

	Windows		powershell Start-Process
	macOS		open
	Other Unix	xdg-open

"x" on WSL is currently unsupported.

Home directory resolution on Windows prefers |expand()| for "~", then falls
back to $HOME, $USERPROFILE, or $HOMEDRIVE plus $HOMEPATH.
